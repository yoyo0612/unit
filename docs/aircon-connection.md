**現在の状態: 未接続。** 機器の検出と通信の確認までは完了しています。エアコンの状態取得と操作は、まだ成功していません。

この文書は、接続を試した経過と、次に取る方法を記録するものです。認証情報（Key、Token、機器 ID）は書かず、必要な値は取得元を記録します。

| 項目 | 内容 |

| # | 方法 | 結果 |

---

## 3. わかったこと

- 東芝 IoLIFE の機器は、LAN から直接操作する公開 API がありません。
- h4de5 の統合は、IoLIFE のアカウントでは使えません。
- 6444 番が開いていることは、この機器が Midea 系の通信方式を使っている可能性を示します。ただし、認証（Token と Key）が揃わないと、状態は取得できません。
- 日本で確実に操作できるのは、赤外線の送信機（Nature Remo など）と、公式の Alexa / Google 連携だけです。

---

## 4. 次に取る方法

### 方法 A: Midea 方式の認証を完成させる（ローカル）
1. Token を、取得元のツールまたはサイトで確認する。
2. `scratchpad\midea_probe.py` を使い、Key と Token を環境変数で渡して、読み取りだけ行う。
   - 成功した場合: 電源、室内温度、運転モードが読める。その後、操作の方法を別途検討する。
   - 失敗した場合: この機器は Midea の方式ではないと判断し、方法 B に進む。

### 方法 B: 赤外線の送信機（ローカル、状態は取得不可）
- Nature Remo などを購入し、リモコン信号を学習させる。
- 電源・温度・モードは送信できるが、現在の状態は読めない。

### 方法 C: 公式の Alexa / Google 連携（クラウド）
- IoLIFE アプリで連携し、音声で操作する。LLM からは直接呼べない。
