## 目的

1. 知識欲の概念を分解し、その構成要素を整理する
2. 自宅 PC で動作するローカル LLM の構成と最適化を明らかにする

## 1. 知識欲の概念化

### 1-1. 知識欲の 7 要素（表 1）

文献整理に基づき、知識欲を次の 7 要素に分解した。

| 番号 | 要素 | 内容 |
|---|---|---|
| 1 | 新規性探索 | 未知の刺激に惹かれ、それを確かめようとする傾向 |
| 2 | 予測誤差の解消 | 予測と現実のズレを埋め、理解を一致させる働き |
| 3 | 情報獲得の動機 | 新しい情報で内部モデルを改善しようとする欲求 |
| 4 | 理解の統合 | 得た情報を既存の知識体系に組み込む過程 |
| 5 | 自己効力感 | 理解できる自分でありたいという有能感 |
| 6 | 探索行動の快感 | 探索そのものが報酬となり行動を継続させる性質 |
| 7 | 意味づけ | 学んだ内容に価値を見出し、自己と結びつける働き |

参照文献: Lisman & Grace (2005); Schultz (1997); Loewenstein (1994); van Kesteren et al. (2012); Deci & Ryan (1985); Kang et al. (2009); Buckner & Carroll (2007)

### 1-2. 『欲望解剖』とクオリア

- **快楽からアディクションへ**: ドーパミンの生成が快楽体験を生み、その再現を求める回路が強化される（茂木・田中, 2013, pp. 28–29）。AI の強化学習と類似し、学習行動の継続性に対応すると考えられる。
- **クオリア**: 「グッとくる」など数値化できない感覚（同書 pp. 22–23）。脳内での処理機構は未解明で、7 要素を支える基盤の可能性がある。

### 1-3. 課題と暫定的結論

- 課題: 参照文献の内容理解が十分ではない。各文献を整理し、7 項目との対応を明確にする。
- 暫定的結論: 知識欲の 7 要素を AI に実装することは、自立的に学習する AI の開発に不可欠であると考えられる。

## 2. ローカル LLM の構築

### 2-1. 実行環境（表 2）

| 項目 | 構成 |
|---|---|
| CPU | AMD Ryzen 9 5950X（16 コア / 32 スレッド） |
| GPU / VRAM | NVIDIA RTX 3070 Ti / 8GB |
| システム RAM | 96GB |
| 推論エンジン | llama.cpp b11675（CUDA 12.4 版）の llama-server |
| モデル | Qwen3.6-35B-A3B（Unsloth 配布、UD-Q4_K_M、約 20.6GB） |
| API | OpenAI 互換 API（ローカル、ポート 8080、API キー不要） |

### 2-2. 推論エンジンの選定（表 3）

- **Ollama**: 不採用。MoE と KV キャッシュの配分を細かく指定しにくい。
- **LM Studio**: 不採用。GUI 中心のため、起動条件を記録しにくい。
- **llama.cpp（llama-server）**: 採用。`--n-cpu-moe` と KV 量子化による調整、OpenAI 互換 API を両立できる。

選定の軸は、(1) 8GB の VRAM に対する細かな配分調整、(2) API による連携、(3) 起動条件を記録できること。

### 2-3. モデルと量子化の選定（表 4）

- **量子化 Q4_K_M**: 品質と容量のバランスが良い。Q3 系は品質低下が大きく、Q5 以上は生成速度（メモリ帯域）を落とすため見送った。
- **モデル Qwen3.6-35B-A3B（MoE）**: 有効パラメータは約 3B。RAM 96GB に収まり、expert を CPU 側に置いても生成速度が実用域に残る。
- **起動設定**: `--n-cpu-moe 40`、`-c 131072`、KV q8_0、`-t 12`、`-ub 2048`。全 expert を CPU に置き、VRAM の余裕を文脈長に回した。

### 2-4. 計測結果

**バッチサイズと expert 配置（表 5）**

| `-ncmoe` | `-ub` | pp（tok/s） | tg（tok/s） | VRAM | 備考 |
|---|---|---|---|---|---|
| 30 | 512 | 140 | 21.9 | 7.94GB | 当初設定。VRAM が溢れて遅い |
| 32 | 2048 | 673 | 28.0 | 7.75GB | 余裕 0.4GB |
| 33 | 2048 | 659 | 27.6 | 7.28GB | 速度優先の候補（余裕 約 0.9GB） |
| 34 | 1024 | 501 | 26.8 | 6.59GB | — |

- 計測条件: 約 4,800 トークンのプロンプトと 256 トークンの生成。1 回の計測。
- `-ncmoe` を 29 以下にすると VRAM が溢れ、生成が 19 tok/s 程度まで低下した。

**文脈長と KV キャッシュ（表 6）**

| 構成 | `-c` | KV | tg（tok/s） | VRAM |
|---|---|---|---|---|
| 速度優先（`-ncmoe 33`） | 16,384 | f16 | 27.6 | 7.28GB |
| 全 expert を CPU（`-ncmoe 40`） | 16,384 | f16 | 23.4 | 3.91GB |
| 全 expert を CPU・f16 | 131,072 | f16 | 23.4 | 6.65GB |
| **採用**：全 expert を CPU・q8_0 | 131,072 | q8_0 | 23.0 | 5.43GB |
| 最大：全 expert を CPU・q8_0 | 262,144 | q8_0 | 23.0 | 7.50GB |

- 長文の検証（文中に埋め込んだ合言葉の想起）: 約 10 万トークンで正しく回答。262,144 設定では約 20 万トークン（200,566）の前半と後半に埋め込んだ 2 つの合言葉を正しく回答した（プロンプト処理 710 tok/s、生成 18.8 tok/s、VRAM 7.54GB）。

### 2-5. 用語

| 用語 | 説明 |
|---|---|
| GGUF | llama.cpp が読み込むモデルの保存形式 |
| 量子化 | 重みを低ビット表現に変換し、サイズと VRAM 使用量を減らす手法 |
| MoE | 複数の expert のうち一部だけを使う構造（A3B は有効パラメータ約 3B） |
| `--n-cpu-moe N` | 先頭 N 層の expert を CPU に配置するオプション |
| KV キャッシュ | 文脈を保持するメモリ。文脈長に応じて増加する。q8_0 で圧縮できる |
| Flash Attention | 注意機構の計算を高速化・省メモリ化する手法 |

## 3. 好奇心駆動型学習の準備

### 3-1. 研究計画（表 8）

1. 環境の把握: MiniGrid 上でランダム行動の挙動を観察する
2. ベースライン: 外部報酬のみで PPO を学習し、学習曲線を記録する
3. 好奇心の追加: ICM または RND を実装する
4. 評価: 探索した状態数、到達率、学習の安定性を比較する
5. 記録: TensorBoard により可視化する

実験環境は Gymnasium、MiniGrid、PyTorch（CUDA 版）。依存関係は `requirements-curiosity.txt` で管理している。

### 3-2. ICM と RND（表 9）

| 手法 | 報酬の定義 | 特徴 |
|---|---|---|
| **ICM**（Pathak et al., 2017） | 順モデルの予測誤差 | 予測しにくい状態を新しいと見なす |
| **RND**（Burda et al., 2018） | 固定したランダムネットワークを別のネットワークが近似する際の誤差 | 実装が比較的容易 |

### 3-3. 知識欲の要素と手法の対応（仮説・表 10）

- 予測誤差の解消 → ICM：予測誤差そのものを報酬とする
- 新規性探索 → ICM・RND：未知の状態ほど報酬が大きくなる
- 探索行動の快感 → 内発的報酬によって探索行動を持続させる
- 情報獲得の動機 → 未知の状態の探索によって内部モデルを改善する

これは作業仮説であり、実験による検証は行っていない。

## 5. 想定される質問と回答の方向性

| 質問 | 回答の方向性 |
|---|---|
| なぜ 8GB の GPU で 35B のモデルが動くのか | MoE の expert を CPU 側に置き、GPU には必要な部分だけ載せるため（`--n-cpu-moe`）。有効パラメータが約 3B のため生成速度も保たれる |
| 量子化すると精度はどれくらい落ちるか | Q4_K_M は品質と容量のバランスが良いとされる。精度の定量評価は今後の課題 |

| ICM と RND の違い | ICM は「次の状態の予測誤差」、RND は「固定ネットワークの予測誤差」を使う |
| 知識欲と好奇心の関係 | 対応は作業仮説であり、検証は今後の課題 |
